# 超重/肥胖合并膝关节不适的患者招募啦！

> 更新时间：2026-09-11 (UTC+8)

体重一直降不下来？反复减肥却难以坚持？

超重/肥胖不仅影响外形与体态，还往往伴随血糖升高、血脂紊乱等一系列代谢异常问题，增加整体健康风险。此外，随着体重增加，膝关节负担也在加重——上下楼梯时膝盖隐隐作痛、走路稍久就不适、蹲起变得困难，这些变化可能正与体重密切相关。

玛仕度肽是一种GCG/GLP-1双受体激动剂，在科学减重和代谢改善方面具有潜力。本研究将在真实临床应用中观察其对体重、代谢指标及关节相关症状的变化情况。

山东大学齐鲁第二医院正在开展“玛仕度肽治疗超重/肥胖患者的真实世界研究：骨性关节炎相关结局的探索性分析”，现面向社会招募超重/肥胖合并膝关节不适的参与者，观察体重、关节症状及代谢指标等方面的变化。
**0****1**
**拟招募条件**

• BMI ≥ 24（超重/肥胖）

• 膝关节不适（如疼痛、僵硬）

• 年龄 18～75 岁

• 配合复查 + 随访

• 无严重胃肠道疾病、肝肾功能不全、心脑血管疾病、胰腺相关疾病、精神疾病、肿瘤等全身性疾病；非妊娠 / 哺乳期 / 计划怀孕女性；近3个月未使用其他减重药物，未接受过膝关节注射 / 手术治疗
