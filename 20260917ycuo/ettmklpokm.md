# 三代试管PGS技术能筛查渐冻症，怀疑此病这5种检查可了解

> 更新时间：2026-09-17 (UTC+8)

渐冻症是一种罕见的遗传性神经退行性疾病，会导致患者肌肉逐渐萎缩和无力。它通常从手部和脚部开始，随着时间的推移会影响呼吸和吞咽能力。由于渐冻症的诊断较难，许多患者在病情发展到后期才被确诊。幸运的是，随着医学技术的进步，现在可以通过三代试管PGS技术筛查渐冻症。该技术可以检测胚胎的基因组序列，识别潜在的遗传缺陷，从而选择健康胚胎进行移植，降低患儿罹患渐冻症的风险。

 如果怀疑自己可能存在渐冻症，以下五种检查可以帮助你了解病情：

## 1. 家族病史调查

 渐冻症具有明显的遗传性，家族中有患有该疾病的成员，那么您自身罹患风险会显著增加。医生会询问您的家庭成员是否出现过类似症状，以及他们的诊断结果。

## 2. 神经学检查

 神经学家会通过触诊、反射测试和肢体功能评估等手段来判断您的肌肉力量、感觉和协调能力。这些检查可以帮助医生识别渐冻症的早期症状，并排除其他可能导致类似症状的神经系统疾病。

## 3. 电位图检查

 电位图检查是一种用于检测神经和肌肉的功能测试。该检查通过测量肌肉和神经传导速度来评估您的神经系统健康状况。如果出现异常，可能提示渐冻症的可能性。

## 4. 肌电图检查

 肌电图检查可以监测肌肉活动和神经信号的传递情况。该检查能够帮助医生判断是否存在肌肉萎缩或功能障碍，从而进一步支持渐冻症的诊断。

## 5. 基因检测

 基因检测是目前最准确的渐冻症诊断方法。通过分析您的DNA样本，可以确定您是否携带导致渐冻症的基因突变。如果检测结果显示您携带有致病基因，那么您可以咨询生殖科医生了解三代试管PGS技术的应用和风险评估。
