# 【关注】抗衰老专题：科学认识光老化

> 更新时间：2026-09-17 (UTC+8)

**抗衰老专题：**

科学认识光老化

**什么是光老化？如何改善？**

皮肤的老化是由内源性因素跟外源性因素叠加引起的复杂过程。内源性因素（主要指年龄因素）是无法避免的自然老化。日光紫外线辐射是外源性因素中导致皮肤老化的主要因素，所以皮肤外源性老化又称为皮肤光老化。

**光老化会给我们的皮肤带来哪些改变呢？**

1. 新生胶原蛋白减少；

2. 胶原蛋白的破坏速度加快；

3. 新胶原的合成和老胶原的分解之间的失衡进一步导致胶原的耗尽，使皮肤变硬，变厚，出现松弛，细纹和皱纹；

4. 糖胺多糖和蛋白多糖增加，导致皮肤干燥症；

5. 造成真皮层血管的减少，造成皮肤细胞营养不良，皮肤发黄；

6. 引起黑色素的增加，产生色素斑疹甚至黄褐斑。

严重的光老化会导致日光性角化病、黑色素瘤等皮肤良恶性肿瘤的发生。

**光老化如何改善？**

1. 皮肤干燥：含有保湿剂的医学护肤品

2. 皱纹：细小的静态纹可以选择点阵激光、强脉冲光

3. 皮肤松弛：强脉冲光、点阵激光、射频

4. 色素斑疹：调Q激光、强脉冲光

5. 毛细血管扩张：强脉冲光、激光

6. 皮肤粗糙、毛孔粗大及肤色暗沉：点阵激光、强脉冲光、化学焕肤术
